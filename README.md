# 進路検索デスクトップ

WPFで進学・就職の受験記録を検索するアプリです。.NET 10 SDKと既存のMySQLデータベースを使用します。

## 進路グラフ

- 年度を選択して、進学・就職の内訳と受験方法別の件数を横棒グラフで確認できます。
- 全登録年度の件数を古い年度から順に表示します。未登録年度は補間しません。
- 棒は各グラフの最大件数を基準に、0件からの長さで表示します。正確な件数も併記します。
- 「この年度の検索・明細を開く」で選択年度を検索へ引き継ぎます。

## ダッシュボード

登録済みの最新年度を自動表示します。総数・進学・就職の件数、受験方法別サマリー、全年度の件数を維持し、年度選択は「進路グラフ」に移しました。「進路グラフ」「年度比較」へ移動できます。

## 年度比較

比較元と対象の2年度を選び、合計・進学・就職の件数、増減、増減率を表示します。初期選択は最新年度とその直前の登録年度です。比較元が0件の場合は増減率を算出しません。同じ年度同士も比較できます。進路グラフと対象年度を共有します。

各ページは表示時と「再読み込み」で集計を取得します。取得失敗時は古い数値・グラフを消して案内を表示します。

件数は受験記録単位です。同じ生徒の複数回受験を含み、人数・進路決定者数・合格者数ではありません。

## CSV保存

検索後に「検索結果をCSV保存」を押して保存先を選びます。最後に成功した検索の全ページを、画面と同じ12列で保存します。条件を変更した場合は再検索してください。日本語をExcelで開きやすいUTF-8 BOM付きで、改行・引用符・カンマを処理し、数式と解釈される文字列には先頭に引用符を補います。

## ビルド・確認

```powershell
dotnet build -c Release
dotnet run --project tests/SmokeTests -c Release
# 既存DBへの読み取り検証を追加（DBは更新しません）
dotnet run --project tests/SmokeTests -c Release -- --database
```

検証ではCSVの特殊文字、合否変換、空結果、年度入力、グラフ集計・並び順・年度切替、年度比較、空データ・取得失敗時の表示、WPF画面の生成とページ遷移を確認します。DB検証は登録済みデータがある環境で、元テーブルとの集計一致・検索一致・ページ切り替え・検索への遷移も確認します。氏名などの個人データはテスト出力に記録しません。
