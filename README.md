# 進路検索デスクトップ

WPFで進学・就職の受験記録を検索するアプリです。.NET 10 SDKと既存のMySQLデータベースを使用します。

## 起動・接続設定

```powershell
.\Run-App.ps1
```

PATH上の`dotnet`に.NET 10 SDKとWindows Desktopランタイムがあることを確認して起動します。Riderから起動する場合は、
「Toolset and Build」の.NET CLIに64bit版（`C:\Program Files\dotnet\dotnet.exe`）を指定してください。32bit版を指定すると起動に失敗します。

初回は「設定 → データベースの接続」で接続情報を入力し、「接続を確認して保存」を押してください。接続できた設定だけを、このWindowsユーザー専用の暗号化ファイル
`%LOCALAPPDATA%\KST-DeCS\database.bin`に保存します。パスワード欄を空欄にすると保存済みのパスワードを引き継ぎます。接続変更後は各画面で再検索・再読み込みしてください。

管理された環境では環境変数`SHINRO_DB_CONNECTION_STRING`
でも指定できます。環境変数がある場合はそちらを優先し、設定画面からの保存を無効にします。接続情報をソースコードやリポジトリに書かないでください。

## 画面共通の決まり

画面の作り方は[UIレビュー](docs/UI-REVIEW-2026-11-09.md)の原則に沿っています。説明文を置く代わりに、配置・アイコン・色で意味を伝えます。

- 進学は青と角帽、就職は橙とかばんのアイコンで、全画面で同じ意味に使います。色は必ず文字かアイコンと組み合わせます。
- 件数は「延べ受験数」です。同じ生徒の複数回受験を含み、人数・進路決定者数・合格者数ではありません。
- 増減は▲▼と数字で示し、良し悪しを表す色は付けません。
- エラー・警告・お知らせは画面上部のバー（アイコン・色・文字）で示し、次に押すボタンを並べます。読み込み中は見出しの下の細いバーと、カードの仮の形で示します。
- ⓘは、知らなくても操作できる定義や算出方法（学科の求め方・増減率の式）にだけ使います。
- 各ページは表示時と再読み込みボタンで集計を取得し、ボタンの左に更新時刻を出します。取得に失敗した場合は古い数値・グラフを消します。

## ダッシュボード

登録済みの最新年度を自動表示します。延べ受験数・進学・就職の件数に、前の登録年度からの増減と構成比を添えます。受験方法別の件数は進学・就職ごとにまとめ、件数に比例した棒と全体に占める割合を表示します。年度別の延べ受験数は棒で並べ、表示中の年度を強調します。棒をクリックすると、その年度の明細（検索）を開きます。各カードのリンクから「進路グラフ」「年度比較」へ移動できます。年度を選んで見るには「進路グラフ」を使います。

## 進路グラフ

グラフは[LiveCharts2](https://livecharts.dev/)（`LiveChartsCore.SkiaSharpView.WPF`）で描画します。卒業年度・学科の選択欄と件数カードは画面上部に固定し、グラフだけがスクロールします。

- 「卒業年度」で最初と最後の年度を選び、その範囲だけをグラフと件数カードに表示します。初期表示は全登録年度です。
  最初の年度を最後の年度より後にすると、もう一方が自動で合わせて動きます。「直近5年度」「全期間」でまとめて切り替えられ、今の範囲に当てはまるボタンが選択状態になります。
- 「学科」で学科を選ぶと、件数カードとグラフをその学科の受験記録だけに絞り込みます。学科はクラス名（例：情報工学科3年）から学年を除いて求め、
  クラスが登録されていない生徒の記録は「未設定」にまとめます。年度の軸と受験方法の色は全学科共通のままです。
- 「卒業年度別の推移」は合計（破線）・進学・就職の件数を折れ線で表示します。登録のない年度は軸に含めません。
- 「進学の受験方法別の推移」は進学の受験方法ごとの件数を折れ線で表示し、「割合」に切り替えるとその年度の進学に占める割合を表示します。
  受験方法「就職」は区分の就職と同じなので、上のグラフに任せます。受験方法が7種類以上ある場合は、全期間の件数上位6種類以外を灰色の「その他」にまとめます。
  色は全期間の順位で決め、青と橙（進学・就職）は使いません。表示範囲を変えても同じ受験方法は同じ色のままです。
- 「受験方法別の件数」は選択範囲の合計を進学・就職ごとにまとめ、件数に比例した棒と全体に占める割合を表示します。
- 凡例はグラフの上にあり、各系列の最後の年度の値を添えます。凡例にマウスを合わせると、その線以外が薄くなります。
- 点にマウスを合わせると件数を表示します。折れ線の点をクリックすると、その年度の明細（検索）を、選んでいる学科の条件付きで開きます。
- ライト・ダーク・ハイコントラストのテーマ切り替えに合わせて、グラフの文字色・背景・系列の色も切り替わります。

## 年度比較

基準年度と比較年度の2年度を選び、延べ受験数・進学・就職の「基準 → 比較」と増減・増減率をカードで表示します。下の表では受験方法ごとの増減を、0を中心に左右へ伸びる棒で示します。初期選択は最新年度とその直前の登録年度です。入れ替えボタンで2つの年度を入れ替えられます。基準年度が0件の場合は増減率を算出しません。同じ年度同士を選ぶと、その旨を表示します。選択は進路グラフの表示範囲とは独立しています。表の右上のリンクから、それぞれの年度の明細を開けます。

## 検索

件数制限・ページ分割なしで検索結果を表示します。検索条件は上部に常に表示し、結果の表だけを縦横にスクロールできます。卒業年度・区分・進路先の3列を固定し、行・列の仮想化と行の再利用で描画を抑えています。

- 条件は卒業年度・受験方法・学科・クラスです。どれも先頭の「すべて」が条件なしです。学科を選ぶと、クラスの選択肢がその学科のクラスに絞られます。
- Enterで検索します。検索中は表の位置に進み具合と中断ボタンを表示し、Escでも中断できます。検索中は条件の編集を止め、取得中の条件との食い違いを防ぎます。
- 「条件をクリア」で進路先の名前と条件をすべて外せます。条件の選択肢を取得できなかった場合は、上部のバーから再試行できます。
- 空白だけの入力は条件なしとして扱い、進路先の`%`や`_`は文字として検索します。
- 条件や接続を変更した場合は、表示中の結果がどの条件のものかを添えて再検索を案内します。
- 区分（進学・就職）はアイコン付き、合否は合格・不合格・未確定のバッジで表示します。「列」ボタンで表示する列を選べます（コース・性別は初期状態で非表示）。
- 受験日や関連マスター情報が欠けていても、他の記録を含めて表示します。

## CSV保存

検索後に「CSV」ボタンを押して保存先を選びます。最後に成功した検索の全結果を、表と同じ順の13列（非表示の列も含む）で保存し、保存できたら画面下に知らせます。条件や接続を変更した場合はCSV保存を無効にするので、再検索してください。日本語をExcelで開きやすいUTF-8
BOM付きで、改行・引用符・カンマを処理し、数式と解釈される文字列には先頭に引用符を補います。

## テーマ

ライト・ダーク・ハイコントラスト・Windowsの設定に合わせる、から選択できます。選択は次回起動にも引き継ぎます。テーマの設定は
`%LOCALAPPDATA%\KST-DeCS\preferences.json`に保存します。

## ビルド・確認

```powershell
.\Run-App.ps1 -Verify
# 既存DBへの読み取り検証を追加（DBは更新しません）
.\Run-App.ps1 -Verify -Database
# 個人データを使わないメイン画面プレビューも生成
.\Run-App.ps1 -Verify -Render
```

検証では検索の中断・条件変更・取得失敗、CSVの特殊文字、欠損データ、年度入力、条件取得の競合、暗号化設定、テーマ保存、グラフ集計、前年度比・構成比、受験方法の区分ごとの一覧、年度比較、学科による検索、エラー・空状態の表示、実際のメイン画面の表示と遷移、ライト・ダークでの可読性と色の切り替え、1万件表示の仮想化、WPFのバインディングを確認します。DB検証では元テーブルとの集計一致・検索一致・全件表示・検索への遷移、区分列と学科検索の集計一致、文字としての検索、画面の応答性、中断後の接続を確認します。氏名などの個人データはテスト出力に記録しません。
