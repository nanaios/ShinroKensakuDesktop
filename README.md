# 進路検索デスクトップ

WPFで進学・就職の受験記録を検索するアプリです。.NET 10 SDKと既存のMySQLデータベースを使用します。

## 起動・接続設定

```powershell
.\Run-App.ps1
```

.NET 10 SDKとWindows Desktopランタイムを確認して起動します。通常のインストール先に加え、ユーザー領域の`kaken-dotnet`と
`.dotnet`も確認します。

初回は「設定 → データベースの接続」で接続情報を入力し、「接続確認して保存」を押してください。接続できた設定だけを、このWindowsユーザー専用の暗号化ファイル
`%LOCALAPPDATA%\KST-DeCS\database.bin`に保存します。パスワード欄を空欄にすると保存済みのパスワードを引き継ぎます。接続変更後は各画面で再検索・再読み込みしてください。

管理された環境では環境変数`SHINRO_DB_CONNECTION_STRING`
でも指定できます。環境変数がある場合はそちらを優先し、設定画面からの保存を無効にします。接続情報をソースコードやリポジトリに書かないでください。

## 進路グラフ

- 年度を選択して、進学・就職の内訳と受験方法別の件数を円グラフで確認できます。
- 全登録年度の件数の構成を円グラフで表示します。凡例は古い年度から順に並びます。
- 凡例には区分ごとの件数と割合を表示します。0件は扇形を描かず、全件0件の場合は空の状態を表示します。
- 「この年度の検索・明細を開く」で選択年度を検索へ引き継ぎます。

## ダッシュボード

登録済みの最新年度を自動表示します。総数・進学・就職の件数、受験方法別サマリー、全年度の件数を維持し、年度選択は「進路グラフ」に移しました。「進路グラフ」「年度比較」へ移動できます。

## 年度比較

比較元と対象の2年度を選び、合計・進学・就職の件数、増減、増減率を表示します。初期選択は最新年度とその直前の登録年度です。比較元が0件の場合は増減率を算出しません。同じ年度同士も比較できます。進路グラフと対象年度を共有します。

各ページは表示時と「再読み込み」で集計を取得します。取得失敗時は古い数値・グラフを消して案内を表示します。

件数は受験記録単位です。同じ生徒の複数回受験を含み、人数・進路決定者数・合格者数ではありません。

## 検索

件数制限・ページ分割なしで検索結果を表示します。検索条件は上部に固定し、結果の表だけを縦横にスクロールできます。卒業年度・受験日・進路先の3列を固定し、行・列の仮想化と行の再利用で描画を抑えています。

- Enterで検索、Escまたは中断ボタンで検索を中断できます。検索中は条件の編集を止め、取得中の条件との食い違いを防ぎます。
- 検索条件を一括クリアでき、条件の選択肢を再読み込みできます。
- 空白だけの入力は条件なしとして扱い、進路先の`%`や`_`は文字として検索します。
- 表示中の結果を取得した条件を示します。条件や接続を変更した場合は、再検索が必要だと案内します。
- 受験日や関連マスター情報が欠けていても、他の記録を含めて表示します。

## CSV保存

検索後にダウンロードボタン（検索結果をCSV保存）を押して保存先を選びます。最後に成功した検索の全結果を、画面と同じ12列で保存します。条件や接続を変更した場合はCSV保存を無効にするので、再検索してください。日本語をExcelで開きやすいUTF-8
BOM付きで、改行・引用符・カンマを処理し、数式と解釈される文字列には先頭に引用符を補います。

## テーマ

ライト・ダーク・ハイコントラスト・システム連動を選択できます。選択は次回起動にも引き継ぎます。テーマの設定は
`%LOCALAPPDATA%\KST-DeCS\preferences.json`に保存します。

## ビルド・確認

```powershell
.\Run-App.ps1 -Verify
# 既存DBへの読み取り検証を追加（DBは更新しません）
.\Run-App.ps1 -Verify -Database
# 個人データを使わないメイン画面プレビューも生成
.\Run-App.ps1 -Verify -Render
```

検証では検索の中断・条件変更・取得失敗、CSVの特殊文字、欠損データ、年度入力、条件取得の競合、暗号化設定、テーマ保存、グラフ集計、年度比較、実際のメイン画面の表示と遷移、ライト・ダークでの可読性、1万件表示の仮想化、WPFのバインディングを確認します。DB検証では元テーブルとの集計一致・検索一致・全件表示・検索への遷移、文字としての検索、画面の応答性、中断後の接続を確認します。氏名などの個人データはテスト出力に記録しません。
