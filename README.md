# 進路検索デスクトップ

WPFで進学・就職の受験記録を検索するアプリです。.NET 10 SDKと既存のMySQLデータベースを使用します。

## ダッシュボード

- 登録済みの最新年度を初期表示し、年度を切り替えて受験記録の総数・進学・就職の内訳を確認できます。
- 受験方法別サマリーと全登録年度の件数を表示します。
- 「この年度の検索・明細を開く」で条件を引き継いで検索します。
- 「再読み込み」でデータを取得し直します。取得失敗時は以前の数値を消して案内を表示します。

件数は受験記録単位です。同じ生徒の複数回受験を含み、人数・進路決定者数・合格者数ではありません。

## CSV保存

検索後に「検索結果をCSV保存」を押して保存先を選びます。最後に成功した検索の全ページを、画面と同じ12列で保存します。条件を変更した場合は再検索してください。日本語をExcelで開きやすいUTF-8 BOM付きで、改行・引用符・カンマを処理し、数式と解釈される文字列には先頭に引用符を補います。

## ビルド・確認

```powershell
dotnet build -c Release
dotnet run --project tests/SmokeTests -c Release
# 既存DBへの読み取り検証を追加（DBは更新しません）
dotnet run --project tests/SmokeTests -c Release -- --database
```

検証ではCSVの特殊文字、合否変換、空結果、年度入力、WPF画面の生成を確認します。DB検証は登録済みデータがある環境で、元テーブルとの集計一致・検索一致・ページ切り替え・検索への遷移も確認します。氏名などの個人データはテスト出力に記録しません。
